# Provider streaming and context

Chat now consumes Server-Sent Events for OpenAI-compatible providers and Anthropic. Text is visible as it arrives. Tool argument fragments remain inert until the provider sends its terminal event and the normal command parser validates the assembled response. A closed or failed stream reports an error instead of executing a partial tool call. Cancellation closes the HTTP call, including a stalled body read. Transient HTTP/network failures receive bounded retries only before any text, tool, or thinking event; Retry-After is capped at 30 seconds. Partial output prevents retries and model fallback. Completed streamed replies trigger auto-speech once even when completion replaces an existing placeholder.

For Anthropic, the system block and final tool definition carry ephemeral prompt-cache markers. Extended thinking is optional in Settings and reserves 2,048 tokens plus room for the response. Effort is exposed for Claude Opus 4.5 only; unknown models do not receive speculative effort parameters.

Native assistant content blocks (including signed thinking and compaction data) are stored in existing message metadata and replayed unchanged. Context trimming enforces the configured message count, keeps user prompts and complete tool/result groups, and omits older groups when one turn exceeds the limit. Native requests and persistence retain the latest compaction anchor with its original user prompt plus a bounded recent suffix; intervening history is omitted. Compatible-provider requests do not pull old native anchors into their window. It does not invent a summary or enable a speculative server-side compaction API.

Mock HTTP and deterministic SSE fixtures cover protocol encoding, partial tools, premature EOF, stream errors, cancellation, persistence, cache markers, and context boundaries. Live provider credentials and on-device audio playback are not available in this environment; those remain deployment acceptance checks.
